# history

Why things in this project are the way they are.

This directory keeps superseded wording, reversed decisions and dead ends. It
also keeps the write-ups of reference sweeps and deep reviews. The pages that
answer questions say what is true now. This directory says what was believed,
and why that changed.

[`../methodology/history.md`](../methodology/history.md) is the rule. This page
is the front page of the directory that the rule points at.

**Do not delete a page here, and do not treat it as filler.** A page here is
often the only record of why a design has its shape. Keep it out of the pages
that answer questions. A reader who wants to use the project must not have to
read about an old mistake to reach the instructions.

---

## The rules on this directory

**Append. Do not edit.** If a later measurement disproves a page, keep the
original words. Write the correction under them.

**Move the wording. Do not summarise it.** A superseded passage comes here in
its original words. A summary loses the detail that made it worth keeping.

**This is not the work order.** The record holds the work order, and
[`../../AGENTS.md`](../../AGENTS.md) says where the record is. A page here that
sessions read for "what next" is a second work order that goes stale.

**This is not the changelog.** The changelog says what shipped, and when. This
directory says what was believed, and why that changed.

## Claims this project has published and later withdrawn

A reader who trusts a document without checking this list trusts sentences
that are wrong. Keep this heading while the list is empty. An empty list is
honest. A missing list reads as "this project has never been wrong".

## A page here reflects what was true when it was written

If a premise later turns out to be wrong, write the correction under it. The
original keeps its wording, because the original is how the item has always
been referred to. A premise that somebody edits in silence is a record of
nothing.

**The prose rules apply here too.** The character set and the no-emoji rule
are checked in this directory like any other. One rule is relaxed: one fact,
one home. [`../methodology/history.md`](../methodology/history.md) says why.
